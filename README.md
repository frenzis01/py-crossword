# Crosswords python
Python program to make a crossword in pdf

## How to use
Install requirements
```
pip install requirements
```

Make an input file with words and clues separated by a ` - ` , like:
```
Pisa - City of the leaning tower
Roma - Caput Mundi
```
Make sure the `INPUT_FILE` constant in `crosswords.py` matches your input file.
Execute:
`python3 crosswords.py`
